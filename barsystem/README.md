# Sistema Tio Paulo

Sistema de gerenciamento de pedidos e produtos para um bar.

## Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven
- Banco H2

## Funcionalidades

- Cadastro de clientes
- Cadastro de produtos
- Criação de pedidos
- Cálculo do valor total

## Conceitos de POO aplicados

- Encapsulamento
- Herança
- Interface
- Polimorfismo
- Associação entre classes

## Estrutura

- controller
- model
- repository
- service
- interfaces
